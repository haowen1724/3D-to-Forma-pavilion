Load a GLB

Your scan must be a .glb file (binary glTF). Convert the OBJ in Blender: File → Export → glTF 2.0 (.glb). Decimate heavy scans to roughly 50k–200k triangles first.

“Preview only” draws the mesh with its own materials but it vanishes when you close this panel. “Place in proposal” creates a real element that is saved, shareable and measurable — but Forma keeps only basic geometry, so colours and textures are dropped.

    Transform

    Forma has no “move element” call, so applying a transform removes the element and re-adds it at the new position. Its path changes; the geometry does not.
